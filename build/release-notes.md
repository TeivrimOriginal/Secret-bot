# Secret-bot 1.1.0

Шифрование файлов в Telegram и расшифровка по ссылке — с входом по passkey
(Windows Hello / отпечаток / Face ID).

## Что нового

* **Passkey.** После первого ввода кодового слова страницу можно открыть по
  отпечатку или PIN: приватный ключ остаётся на устройстве, сервер хранит
  только публичный. Повторно вводить слово с того же устройства не нужно.
* **Сайт на FastAPI.** Веб-слой переведён с aiohttp на FastAPI + uvicorn;
  сайт и бот живут в одном процессе и одном event loop.
* **Кликабельные ссылки** в сообщениях бота (личка и группа).
* **Установщик для Windows.** Ничего доустанавливать не нужно: Python и все
  библиотеки внутри.

## Установка

1. Скачайте `SecretBot-1.1.0-setup.exe` и запустите — права администратора
   не требуются, программа ставится в профиль пользователя.
2. Откройте файл настроек (ярлык «Настроить (secret-bot.env)» в меню Пуск
   или предложение в самом конце установки) и впишите минимум:

   ```
   BOT_TOKEN=123456:AA...           ; токен от @BotFather
   BASE_URL=https://ваш-домен        ; публичный адрес сайта, БЕЗ слеша
   ENABLE_WEB=1
   ```

3. Запустите «Secret-bot» из меню Пуск.

Портативная версия: распакуйте `SecretBot-1.1.0-portable.zip` и запустите
`SecretBot.exe` — установка не нужна, настройки там же рядом (`secret-bot.env`).

## Важно про passkey и HTTPS

WebAuthn работает только по HTTPS. Для локальной проверки подойдёт
`BASE_URL=http://localhost:8080` — браузеры считают localhost защищённым
источником. Для доступа с других устройств нужен HTTPS
(домен + сертификат, например за nginx).

## Проверка

```
SecretBot.exe --selftest     самопроверка: крипто, база, сайт, страница
SecretBot.exe --version
```

## Где что лежит

* Программа: `%LOCALAPPDATA%\Programs\Secret-bot`
* Данные: `%APPDATA%\SecretBot` — база `links.db` и настройки
  `secret-bot.env`. Удаление программы эти данные **не** затрагивает.
